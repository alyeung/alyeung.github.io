# alyeung.github.io

Personal GitHub Pages site for Allan Yeung.

The root site is a lightweight professional homepage focused on product, data,
cloud, automation, and practical systems work.

## Live site

- Homepage: <https://alyeung.github.io/>
- Archived General Assembly project: <https://alyeung.github.io/archive/ga-final-project/>

## Structure

- `index.html` - current homepage
- `styles.css` - current homepage styles
- `archive/ga-final-project/` - preserved snapshot of the older General Assembly front-end project
- `final_project_template/` - original project path kept for backwards compatibility

Older course exercises remain in the repository as historical reference, but are
not featured from the current homepage.
